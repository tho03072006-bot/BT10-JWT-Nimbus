JWT · JJWT

Xác thực Stateless bằng JSON Web Token

Spring Boot 3, Spring Security 6 và thư viện JJWT của bài giảng.

  1. Đăng nhập gửi POST /auth/login, server ký JWT (HS256) bằng JJWT.
  2. Trình duyệt giữ token, mỗi request gửi kèm Authorization: Bearer.
  3. Server kiểm tra chữ ký và hạn dùng, không lưu session.
